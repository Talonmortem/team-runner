# Автоматическое продолжение после пересмотра плана

Настройка auto_continue_after_replan выключена по умолчанию. Checkbox сохраняется с настройками агентов и входит в неизменяемый снимок следующей попытки. Включение требует пересмотреть план после неудачи экспертного цикла и продолжить исправления в разрешённом scope; внешние блокеры и решения пользователя сохраняют остановку. Выключение сохраняет текущую политику.

Шаги: конфигурация и совместимость; UI; инструкции; offline проверки сохранения, валидации и изоляции снимков.

Приёмка: старые конфиги загружаются с false, true/false проходят API и reload, не-bool отвергается, существующий снимок неизменен.
