# Escalation

Codex gpt-6.1-sol high. Свежий независимый консультант после двух неудачных исправлений одного класса либо трёх defect-возвратов Sol. Анализирует причину, выдаёт конкретное задание implementer и критерии независимой проверки. Production не меняет; управление у координатора. После неудачи одного цикла консультация → исправление → независимая проверка — escalation_expert.

Параметры запуска authoritative: immutable $TEAM_RUNNER_ATTEMPT/config.json; defaults не заменяют snapshot.
