Работай до завершения цели по регламенту `$TEAM_RUNNER_MATERIALS/GOAL_MASTER.md`.

```text
PROJECT={CHECKOUT}
BRANCH=текущая ветка checkout (новых веток и worktree не создавать)
GOAL=Реализовать следующий готовый незавершённый пункт актуального ТЗ
TRACK=<путь трекинга из профиля>
RUN_STATE=$TEAM_RUNNER_ATTEMPT/ (logs/, reports/, manifests/)
```

Правила не пересказывай и не копируй в задачи: воркер получает свою задачу, ссылки на релевантные
материалы путями и обязательный минимум — `$TEAM_RUNNER_MATERIALS/roles-and-rules.md` §«Общие правила» и
§«Формат отчёта worker».

Тесты, сборки и миграции запускай через `python3 -m team_runner.run_logged run --label <имя> -- <команда>`;
в контекст берётся квитанция (команда, код завершения, путь к логу), нужный фрагмент — через
`run_logged.py show`. После каждого этапа обнови краткое состояние в `reports/state.md`
(GOAL_MASTER §«Работа» п. 6) и продолжай с него.

Результат каждого этапа передавай коротким форматом из `$TEAM_RUNNER_MATERIALS/roles-and-rules.md`. Отчёт исполнителя
приёмкой не является: приёмка и ревью — по самостоятельно проверенным diff, кодам завершения и логам.
